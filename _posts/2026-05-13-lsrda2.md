### 13->14레벨
패스워드는 `/etc/bandit_pass/bandit14`에 저장되어 있으며 사용자 `bandit14`만 읽을 수 있다. 
현재 홈 디렉터리에 있는 SSH 개인키를 활용하여 비밀번호 없이 `bandit14` 계정으로 로그인한 뒤 패스워드를 추출해야 한다.<br>

출력한 결과물을 복사하고 `chmod 600 sshkey.private` 으로 개인키 권한을 안전하게 설정한 뒤 `ssh -i sshkey.private bandit14@bandit.labs.overthewire.org -p 2220` 명령으로 개인키 인증을 사용해 `bandit14`에 접속한다. 이제 `cat /etc/bandit_pass/bandit14`을 사용하여 패스워드를 획득한다.<br>

### 14->15레벨
`localhost`의 30000번 포트에 현재 레벨의 비밀번호를 전송하여 패스워드를 추출해야 한다.<br>

`nc localhost 30000`을 통해 내 컴퓨터의 30000번 포트로 접속해서 현재 레벨의 비밀번호를 전송하여 패스워드를 추출하였다.<br>

### 15->16레벨
SSL/TLS 암호화 통신으로 `localhost:30001` 에 비밀번호를 전송하여 패스워드를 추출해야 한다.<br>

`cat /etc/bandit_pass/bandit15` 로 현재 레벨 비밀번호를 확인한 뒤, `cat /etc/bandit_pass/bandit15 | openssl s_client -connect localhost:30001 -quiet` 명령으로 SSL/TLS 연결을 만들어 비밀번호를 전송한다. `-quiet`은 불필요한 인증서 출력을 숨기고 EOF 처리 문제를 해결하고 응답으로 비밀번호를 추출하였다.<br>

### 16->17레벨
31000~32000 포트 범위에서 열린 포트를 찾고, SSL 서버를 식별한 뒤 비밀번호를 전송해 다음 레벨의 SSH 키를 추출해야 한다.<br>

`nmap -p 31000-32000 localhost`로 열린 포트를 확인하고 `nmap -p 31000-32000 -sV localhos`t 로 각 포트의 SSL 사용 여부를 확인한다. SSL 사용 포트마다 `cat /etc/bandit_pass/bandit16 | openssl s_client -connect localhost:포트 -quiet` 명령을 실행하여 RSA 개인키가 응답으로 오는 포트의 키 내용을 복사하여 WSL 로컬에서 nano bandit17.ky로 파일 생성 후 저장하여 `chmod 600 bandit17.key` 로 권한을 설정한 뒤 `bandit17`에 접속한다.<br>

### 17->18레벨
`passwords.old` 와 `passwords.new` 두 파일을 비교해 변경된 줄을 찾아 다음 레벨 비밀번호를 추출해야 한다..<br>

`diff passwords.old passwords.new`을 통해 두 파일의 차이점 을 비교하고, `diff passwords.old passwords.new | grep ">"`을 통해 `>`가 포함된 줄만 추출한다.<br>

### 18->19레벨
`.bashrc` 가 자동 로그아웃하도록 수정된 `bandit18` 계정에서 `readme` 파일을 읽어 비밀번호를 추출해야 한다.<br>

`bandit18`에 접속하려 하면 `.bashrc`로 인해 자동 로그아웃이 되기 때문에 접속할 때 실행할 명령어를 동시에 입력하여야 한다. 그러므로 `ssh bandit18@bandit.labs.overthewire.org -p 2220` 끝에 `"cat readme”`을 입력하여 비밀번호를 추출한다.<br>

### 19->20레벨
홈 디렉터리에 있는 `setuid` 바이너리를 사용하여 다음 레벨로 진입해야 한다.<br>
